# CareFlow Documentation



\## Problem

Hospital managers don't know why waiting time in the emergency room is

so high. The average wait time doesn't show what really happens to a

patient step by step.



\## Goal

Use hospital event data to find where patients get stuck, and show it

in a dashboard so the hospital can fix it.



\## Tools we use

\- Python: to create sample hospital data

\- BigQuery: to store the data

\- dbt: to clean the data

\- PM4Py: to find the patient process map

\- Power BI: to make the dashboard
